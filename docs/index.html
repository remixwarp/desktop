RemixWarp Desktop

重新构建自由，离线可用 · 基于 TurboWarp 的中文增强版

当前版本：v1.0.0

Windows 10 及更高版本

下载安装程序，运行后按提示安装即可。

  • 下载安装程序（64 位，推荐）

如果出现 Windows SmartScreen 提示，请点击“更多信息”后选择“仍要运行”。

macOS 12 及更高版本

下载 .dmg 文件，打开后将 RemixWarp 拖入“应用程序”文件夹。如果提示已存在，请选择“替换”。

  • 下载适用于 macOS 12 及更高版本

Linux

根据你的发行版选择对应的安装包。推荐使用 .deb 或 AppImage。

Debian / Ubuntu / Linux Mint（64 位）

  • 下载 .deb（x86 64 位）

AppImage（x86 64 位）

  • 下载 .AppImage（x86 64 位）

tar.gz（x86 64 位）

  • 下载 .tar.gz（x86 64 位）
